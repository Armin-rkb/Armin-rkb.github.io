# armin-rkb.github.io

My portfolio, hand-built in plain HTML, CSS and JavaScript (no Webflow, no build step).

## Edit content

- **Projects and skills:** `data.js`. Each project is one entry; a YouTube id in `video` gives the card thumbnail and the player.
- **Experience, about and contact text:** `index.html`.
- **Colours and layout:** the variables at the top of `styles.css`.

## Preview locally

```
python -m http.server 8000
```

Then open http://localhost:8000.

## Publish

This repo is named `Armin-rkb.github.io`, so GitHub Pages serves it at https://armin-rkb.github.io
(Settings → Pages → Deploy from branch → `main` / root). Every push to `main` updates the site.

## Hidden extra

Type the Konami code (↑↑↓↓←→←→BA) on the page.
